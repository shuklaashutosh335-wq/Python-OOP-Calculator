🧮 Python OOP Calculator

A simple and interactive calculator developed using Python and Object-Oriented Programming (OOP) concepts.

🚀 Features

This calculator supports 7 mathematical operations:

1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
5. Percentage (%)
6. Modulus (%)
7. Power (**)

🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)

📚 OOP Concepts Used

- Classes and Objects
- Methods
- Encapsulation of calculator operations

▶️ How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the "calculator.py" file.
5. Select an operation and enter the numbers.

🎯 Project Objective

The objective of this project is to understand Python programming fundamentals and implement basic Object-Oriented Programming concepts through a practical calculator application.
